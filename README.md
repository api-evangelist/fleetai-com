Fleet (Fleet AI, Inc.) is an applied research lab that builds environments: diverse, high-fidelity simulated training gyms that model real-world work so AI agents can practice tasks while humans provide supervision. It works with frontier labs, hyperscalers and enterprises on evals and environments for agents, and is backed by Sequoia Capital, Menlo Ventures and SV Angel. Its public site lists no public API; its documentation host (docs.fleetai.com) redirects to a login page.

**Areas:** Company · Artificial Intelligence · AI Agents · Reinforcement Learning Environments · Evaluations · Simulation · Training Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Fleet: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
